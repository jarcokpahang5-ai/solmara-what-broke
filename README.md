# solmara-what-broke

One line for make.fun's "Say What Actually Broke" bounty: the server that was supposed to save your work spent an hour confidently saving nothing. `main.py` prints the line and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
